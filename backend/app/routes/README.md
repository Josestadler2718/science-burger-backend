# routes/

Placeholder folder. Will hold one FastAPI `APIRouter` module per
resource, e.g.:

- `products.py` → `GET /api/products`, `GET /api/products/{id}`
- `orders.py` → `POST /api/orders`, `GET /api/orders/{id}`
- `contact.py` → `POST /api/contact`

Not implemented yet — this stage of the project is front-end only.
